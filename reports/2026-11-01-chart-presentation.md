# 图表排版与比例调整

根据用户提供的桌面截图调整：原图的工具栏、独立 AI 操作行、读数与图例分成多层，顶部空白过多；月 K 只有二十余根，实体宽度却固定最多 12px，导致细小蜡烛散在宽画布中；坐标和数字也偏小。

本轮将 AI 操作并入图表工具栏，合并时间和指标图例区域，收紧股票标题与图表之间的间距。图表绘图区使用当前容器宽度及明确的像素高度，桌面 390px、手机 330px；主图和副图统一左右坐标边界，避免横向拉伸造成比例变化。月 K 实体随实际间距增宽，最大 28px，保留真实影线；纵轴增加少量留边。坐标字号提升为桌面 12px / 手机 11px，补上右侧最新价标签，成交量提高可见度。日内成交量颜色按前一价格点判断，不再因采样点 open=close 而全部着同一种颜色。

宽屏内容有最大宽度，右侧市场概览保持独立窄列；平板改为下方两列，手机改为单列。数字沿用上轮统一的界面字体，保留必要的字号和粗细层次。折线点数、K 线 OHLC、指标计算和五日跨日断线不变。

预览 HTML 响应增加 Cache-Control: no-store，Nginx 的 index.html 同步配置；新版本链接可以绕过旧页面缓存。用户截图中的“1日 / 1周”与旧字体属于此前界面，本次公开页面核对以“分时 / 五日”和统一字体为准。

验证：生产构建、ESLint 和 18 项前端测试通过。`chart-presentation-browser-check.json` 覆盖 1920 / 1440 / 1200 / 1024 / 375 像素，稳定布局下主图横纵缩放均为 1，最新价标签均在画布内；没有横向溢出或 JavaScript 错误，五日保持五段。深浅主题、中英文和红绿切换正常。受控 AI 联调回归也通过，包含分析按钮、图表标注、周期切换与新闻分析。

本轮未修改行情数据源或发布 Render。截图位于忽略提交的 `.local/chart-presentation-*.png`。
