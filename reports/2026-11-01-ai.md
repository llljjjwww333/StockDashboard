# AI 接口配置、资讯分析与行情图标注

## 使用

1. 右上角「设置」添加接口，填写名称、地址、模型和 API Key。
2. 点击「测试连接」，再「保存并使用」。可以保存多套配置，在分析按钮旁直接切换。
3. 资讯页点击「AI 分析」，读取最新财经新闻及市场概览，按当前关键词和来源筛选分析。
4. 看盘页选股票和周期后点击「AI 分析」，系统读取该周期的 OHLCV、报价、新闻、指数及计算指标，返回分析与图上标注。
5. 点击图中编号或下方关键点按钮查看依据；「清除」移除结果。切换股票、周期、接口或修改接口配置会使旧分析失效。

界面保持短标签和直接操作，没有增加说明卡或免责声明。图表继续自动刷新，标注按时间戳重新定位，未落在当前窗口的标注不强行绘制。

## 接口

- 支持 Chat Completions 和 Anthropic Messages 两种协议，可以填写基础地址或完整接口地址。
- 预设提供 DeepSeek、通义千问、Claude 地址；模型 ID 由用户填写。也支持自定义服务商。
- 服务端按协议设置 Bearer 或 x-api-key；不会把 API Key 写入 URL、分析结果或日志。
- 配置保存到当前浏览器。密钥默认仅保存在当前会话；勾选「在此设备记住密钥」后才写入浏览器持久存储。没有账号同步。
- 新增 `POST /api/v1/ai/providers/test` 和 `POST /api/v1/ai/analyze`。临时 HTTPS 预览代理只放行这两个 AI POST 入口。
- 默认拒绝内网 / 本机模型地址。私有部署需要本地模型时，可显式设置 `AI_ALLOW_LOCAL_PROVIDER=1`；公网预览未启用该设置。

预设与协议参考：[DeepSeek](https://api-docs.deepseek.com/api/create-chat-completion/)、[通义千问区域地址](https://help.aliyun.com/en/model-studio/base-url)、[Claude API](https://platform.claude.com/docs/en/api/overview)。

## 数据与标注

- 点击分析才调用模型，不自动循环调用。
- 看盘请求明确包含当前 ticker、period 和 interval，服务端重新获取相关数据，不依赖浏览器拼接行情事实。
- 指标包含可计算窗口内的 MA5 / MA20 / MA60、Wilder RSI14、MACD 及信号线；不足窗口的指标返回空值。
- 服务端从实际 OHLCV 生成支撑、阻力、放量、突破候选位置。模型选取候选并给出简短说明，最多保留六个关键点。
- 模型必须引用已有候选 ID。时间、价格、位置由服务端映射回原始行情，模型虚构的 ID、价格和日期不进入图表。
- 历史数据不足、模型无内容、格式错误或没有有效标注均返回明确错误，不生成假分析。
- 新闻分析返回结论、依据和关注事项，记录实际使用的新闻来源、数量与时间。

## 验证范围

- 后端 27 项测试通过，含 11 项 AI 测试：两种协议、鉴权错误脱敏、JSON 参数兼容回退、指标、标注锚定、周期传递、新闻筛选与数据不足时停止调用。
- 前端构建、lint、diff 检查通过。
- `scripts/check_ai.cjs` 使用独立测试服务验证设置保存、连接测试、多接口切换、默认不持久化密钥与主动记住、图上标注、无效标注丢弃、点击查看、切换周期清除、新闻分析和密钥错误处理。
- 浏览器尺寸覆盖 375 / 1024 / 1440px，无 JavaScript 异常；详见 `ai-browser-check.json`。
- 真实 HTTPS 预览已检查设置入口、AI 按钮和 POST 转发。普通行情与模型配置分开，不需要在聊天中提供密钥。
- 模型返回及分析数据的联调采用明确标记的受控测试服务，没有使用用户的真实模型密钥，也没有测量模型分析准确率。真实服务商的有效调用需要用户在设置中填写接口并测试。
- 当前更新到本地与临时 HTTPS 预览，尚未提交 GitHub 或发布到 Render；Render 原站仍为旧部署。
