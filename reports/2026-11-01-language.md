# 中英文界面

设置新增中文 / English 选项，立即生效并保存到浏览器，同源标签页同步。默认中文；已有主题、涨跌配色及 API 配置独立保留。

翻译范围：导航、自选、搜索、行情读数与周期、主副图指标、市场分布和排行、新闻筛选、弹窗、AI 接口设置、操作状态与常见错误。日期、时间和紧凑数字分别使用 zh-CN / en-US；交易所时区保留。新闻原文、股票名称、用户输入的接口名称不自动翻译。

AI 请求增加 language=zh/en，后端向模型指定对应输出语言；英文标注默认名称和标签长度适配。切换语言会中止旧请求、隐藏旧结果，避免旧语言响应覆盖新界面。真实外部模型未提供密钥，本轮只验证受控接口协议与结果显示。

验证通过：生产构建、ESLint、12 项前端测试、29 项后端测试。字面翻译键检查未发现缺项。双语浏览器检查覆盖即时切换、刷新保存、标签页同步、15 项指标、图表读数、中文及英文受控分析输出、375 / 1024 / 1440 像素下的三个页面与设置弹窗；无横向溢出或页面 JavaScript 错误。既有 AI 联调及主题配色浏览器检查也通过。
