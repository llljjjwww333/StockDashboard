# 页面主题与涨跌配色

设置新增两组选项：深色 / 浅色、绿涨红跌 / 红涨绿跌。选择即时生效，无需保存 API 配置；刷新后保留，并同步同源浏览器标签页。

主题覆盖导航、自选、行情图、指标、设置、新闻弹窗与搜索。浅色主题使用独立的指标线与标注颜色，提高白底对比度。金融方向使用独立的 up/down 色彩变量，连接状态、错误和删除操作保留原本语义。

验证：前端生产构建、ESLint、12 项既有前端测试通过。`scripts/check_appearance.cjs` 在真实行情页面验证四种主题 / 配色组合，检查 K 线、成交量、MACD 柱及正负涨跌数字的实际计算样式，刷新持久化，以及 375 / 1024 像素布局；无页面 JavaScript 错误。结构化结果见 `appearance-browser-check.json`，截图在忽略提交的 `.local/appearance-*.png`。
