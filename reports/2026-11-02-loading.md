# 行情加载与 K 线切换修复

日期：2026-11-02。已更新本机服务和 Cloudflare 临时预览；未推送 GitHub 或更新 Render。

## 修改

- 图表类型与周期由同一个状态管理。分时 / 五日点击 K 线，进入上次日线周期，首次为 1 月；K 线下只显示 1 月 / 3 月 / 1 年。切换导航和连续点击保留选择。
- 浏览器按股票、周期和采样间隔缓存并合并并发请求，同标签页刷新可从 sessionStorage 恢复。切换周期时先绘制匹配缓存，再后台更新；失败保留已有真实数据及过期标记。
- 后端历史缓存过期后立即返回真实缓存，并合并后台刷新。失败不会更新原始数据时间，并限制重试频率。
- 主源超过 600 毫秒未返回时启动备用源，适用于分时、中美股日 K。美股分时仍保持 1 分钟粒度；备用请求按所选 1 日 / 5 日获取，避免分时也下载五日。
- 北交所日 K 优先东方财富前复权数据。920117 原腾讯接口只有当天一根，本轮东方财富返回月内 18 根；同时修复一根真实 K 线不能绘制的问题和成交量柱宽。
- 主图先加载，再补取指标历史。API 和预览静态资源压缩，带内容哈希的资源长期缓存，HTML 保持不缓存。Docker nginx 配置也补充压缩与资源缓存。

## 验证

- 前端 27 项测试、后端 48 项测试通过；TypeScript / Vite 构建及 ESLint 通过。
- 受控浏览器测试故意延迟及挂起网络响应：切回缓存图表 66 毫秒，同标签页刷新恢复图表 134 毫秒；均在网络尚未返回时绘制。覆盖单根 K 线、连续点击、保留日线周期和导航切换。见 `loading-browser-check.json`。
- 本机真实 API 本轮取样：600519 分时 0.352 秒、月线 0.273 秒；920117 分时 0.250 秒、月线 0.183 秒；AAPL 分时 0.539 秒。过期缓存 0.071 秒返回，随后确认后台数据时间已更新。见 `loading-live-check.json`。
- 预览 JS 压缩后 86,442 字节，原始 265,246 字节；AAPL 分时 JSON 压缩后约 6.9 KB，原始约 52.6 KB。已核验 HTML no-store、哈希资源 immutable 和 gzip 响应。
- 公网真实浏览器：五日点击 K 线进入月线，连续点击保持 K 线，选择三月后往返五日仍恢复三月；缓存切回 41 毫秒。375 / 1024 / 1440 宽度无横向溢出，无 JavaScript 异常。见 `loading-public-check.json`。

## 实测边界

公网首次整页到图表本轮仍为 8.675 秒，改前取样为 8.613 秒；该次没有证实整页首访变快。历史接口公网响应约 1.1–3.2 秒，整页还包括临时隧道和页面资源传输。修复的稳定收益是缓存恢复、周期往返和过期缓存无需等待源站。

途中一次免费源 SSL 握手超时，公网首图为 19.888 秒、本机 AAPL 分时为 8.691 秒，原始记录保留在 `loading-public-initial.json` 和 `loading-live-initial.json`。免费源与公网链路仍可能波动，以上为单次取样，不能解释为延迟保证。未测量交易所端到端行情延迟，也未运行 Docker 容器或真实付费 AI 接口。
