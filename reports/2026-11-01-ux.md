# 第二轮网站体验优化

日期：2026-11-01。本轮沿用第一轮的免费行情方案，未发布到公网。入口仍为 http://127.0.0.1:5173。修改前的 9 个主要文件保存在根目录 `.baseline-before-ux-upgrade.zip`。

## 已修复 / 增加

| 问题 | 改动 |
| --- | --- |
| 页面至少 1180px，手机和平板需要拖动整页 | 改为响应式布局；手机自选股横向滑动，内容单列，市场与新闻分别适配 |
| 很多文字只有 7–9px，且部分数值低对比 | 放大正文、报价、指标和主要说明文字；提高辅助文字对比度 |
| 在窄桌面隐藏成交额和换手率 | 六项关键指标保留，窄屏改为两行排列 |
| 最新价更新，日内高低点、成交量等可能仍停留旧快照 | HTTP 与 WS 保留完整报价快照，并从同一快照显示价格、成交量、日内高低点、成交额与换手率 |
| 慢 HTTP 结果可能覆盖更新的 WS 报价 | 按源站报价时间、抓取时间判断新旧，拒绝倒退覆盖 |
| 图表只有折线；按当天涨跌配色会误导长期曲线 | 增加 K 线切换和 MA20；折线按所选区间变化配色，K 线逐根按开收盘配色 |
| 图表时间受浏览器时区影响、鼠标指向与绘图边界有偏差 | 标注北京 / 美东时间；修正绘图区坐标、重复刻度及悬停边界；日线不显示虚构的成交时刻 |
| 每秒时钟触发整个工作台重新渲染 | 时钟移至独立组件，图表使用 memo，避免与时钟一起重算 |
| 搜索只覆盖少量固定美股，A 股 ETF 被过滤 | 美股增加腾讯在线搜索及短缓存，保留本地回退；A 股接受基金类别，可查 510300 等 ETF |
| 搜索条件变化后短暂显示旧结果，空查询后可能残留加载状态 | 结果绑定查询与市场，取消过期请求；增加超时、错误态和上下键 / 回车选择 |
| 主市场与搜索市场不同步 | 切换主市场时同步搜索范围并清空旧查询 |
| 新闻无法筛选、无链接的新闻点击没有反应 | 增加关键词和来源筛选；无外链新闻在对话框内阅读摘要；支持 Esc 关闭 |
| 新闻失败后研究台仍持续显示“加载中” | 区分加载、空列表和错误；断线提示在手机内容区也可见 |
| 关联股票可能跨市场、未知股票默认归入科技股 | 仅显示同市场、已知行业关联，未知行业返回空列表 |
| 外部字体加载依赖 Google Fonts | 去掉远程字体请求，使用本机字体回退 |

## 仍然不够完善的部分

1. **图表深度**：目前是基础 K 线、折线、成交量和 MA20，缺少拖动缩放、更多指标与多标的对比；历史图表按分钟级轮询，尚未逐笔驱动最新 K 线。
2. **选股与提醒**：没有完整的条件筛选器、价格提醒与提醒历史。目前仍以查看行情和资讯为主。
3. **自选股管理**：数据仅保存在当前浏览器，没有导入导出、删除撤销或账户跨设备同步。浏览器清理数据后可能丢失观察列表。
4. **资讯深度**：当前来源提供的摘要在后端限制长度，站内对话框显示摘要；不承诺原文全文。缺少公司公告、财报和经济事件的专门聚合。
5. **市场覆盖与时效**：美股免费源为延时报价，市场宽度为样本概览；交易时段调度尚未使用完整交易所假日表。第一轮留下的盘中端到端延迟验证仍待开市进行。
6. **AI 与文档一致性**：后端保留 AI 接口，但当前前端没有完整的 AI 配置和分析操作入口；旧 README 中这类功能描述不能视为已验证的端到端能力。
7. **部署与规模**：当前确认本地网页可用；公网发布、容器运行、大量用户压力测试和多个后端进程共享订阅仍未验证。

这些属于明确的后续功能或验证范围，本轮没有把它们包装成已经完成的能力。
