# 行情下方信息补齐

行情图下方扩为 12 项：今开、昨收、最高、最低、振幅、量比、成交量、成交额、换手率、市盈率、市净率、总市值。宽屏两排，每排六项；平板和手机每排三项。中英文标签与现有主题配色沿用设置。

后端报价 schema 增加 volume_ratio、pe_ratio、pb_ratio、market_cap，HTTP、共享缓存和 WebSocket 使用同一完整快照；前端不另发估值轮询请求。总市值转为原币种单位，界面按人民币 / 美元标识与当前语言格式展示。缺失值为 null / `--`，负市盈率保留源值，非有限数值拒绝。

字段映射依据 [easyquotation 的腾讯解析实现](https://raw.githubusercontent.com/shidenggui/easyquotation/master/easyquotation/tencent.py) 与源端实测：A 股量比 49、市盈率 39、市净率 46、总市值 45（亿元）。[腾讯美股官方页面脚本](https://st.gtimg.com/quotes/us/bundle.f038d542.js) 的报价转换也将 39 用作市盈率、45 用作总市值、48 / 49 用作 52 周高 / 低；美股不可沿用 A 股第 49 项作为量比。美股当前报价源没有可确认的量比、市净率映射，这两项为空，不做日成交量近似。

本轮源端样本：600519 量比 1.36、市盈率 21.18、市净率 6.42、总市值 1740176000000 元；AAPL 市盈率 39.52、总市值 5029592253000 美元。样本时间见 `quote-metrics-browser-check.json` 的 as_of，均为最近交易日报价，并非周末实时成交。

验证：生产构建、ESLint、12 项前端测试和 32 项后端测试通过；新增测试覆盖两市场字段差异、单位、缺失值、负市盈率、非有限输入及单只股票路径。浏览器使用实际行情验证 12 项渲染、A 股数值与接口一致、切换美股不残留量比、中英文标签、375 / 1024 / 1440 像素布局，无页面 JavaScript 错误。截图在 `.local/quote-metrics-*.png`。
